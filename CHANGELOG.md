# Changelog

## 0.1.0 — first public preview

- Portable Windows recorder and local dashboard with Steam-library discovery.
- Visible Skip this packet control before and during recordings; persistent skips and continued suggestions beyond the starter tasks.
- Multiple tasks per recording, immutable marker times and review of uncertain actions.
- Explicit upload consent, manual send, stable extension identity and duplicate prevention.
- Per-user data paths and locally calibrated optional menu return; no personal templates or machine paths shipped.
- Smaller progress responses, cached catalogs and conditional public-API requests.
- Durable marker recovery snapshots and state backups; recorder shutdown is awaited before export.
- Hash-checked bootstrap downloads, pinned engine revision, synthetic tests, clean-profile checks and an allowlisted release package.

This preview does not guarantee account safety, absence of game crashes, or successful menu matching on every display layout. Real-game compatibility depends on the upstream collector and installed game build.
